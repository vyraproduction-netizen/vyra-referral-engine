# VYRA Referral Engine

VYRA is an autonomous referral and affiliate content engine focused on image and video enhancement tools.

## Mission

Discover useful products, create evidence-based content, publish it, track referral performance, and continuously optimize the content system.

## Operating model

Discover → Research → Draft → QA → Publish → Distribute → Measure → Optimize → Repeat

## Core principles

- Referral / affiliate revenue only
- No direct client communication
- Automated content workflow
- Evidence-based product information
- Mandatory affiliate disclosure
- No fabricated reviews, tests or claims
- Automated error recovery
- Analytics-driven optimization
