# VYRA AI Agents

This directory contains the autonomous agents that operate the VYRA Referral Engine.

## Agents

- topic_scout — discovers promising topics and search opportunities
- research — collects and structures factual information
- content — creates drafts from approved research
- qa — checks factuality, links, formatting and compliance
- links — manages referral links and tracking
- analytics — processes performance data
- optimizer — identifies winners and generates improvement tasks

## Rule

Agents must operate from structured data and must not invent product claims, reviews, prices, commissions or test results.
